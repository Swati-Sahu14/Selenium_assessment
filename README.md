## 🔎 Selenium Topics

| Category | Topics |
|---|---|
| **WebDriver** | Browser launch, navigation, window handling |
| **Locators** | ID, Name, Class, Tag, Link Text, Partial Link Text, CSS, XPath |
| **XPath** | Attributes, Text, Contains, Starts-with, Ends-with, Indexing, Surroundings, Axes |
| **WebElement** | Click, SendKeys, Clear, GetText, GetAttribute, GetTagName, GetCssValue |
| **Validation** | Displayed, Selected, Enabled, Size, Location, Rect |
| **Synchronization** | Implicit Wait, Explicit Wait, Fluent Wait, WebDriverWait, Expected Conditions |
| **Dropdowns** | Select, selectByIndex, selectByValue, selectByVisibleText |
| **Suggestions** | Dynamic suggestions using findElements |
| **Actions** | Hover, Click, Double Click, Right Click, Drag & Drop, Keyboard actions |
| **Advanced** | Screenshots, JavaScriptExecutor, Iframes, Alerts, Popups |

## ▶️ Run Locally

### Clone

```bash
git clone https://github.com/Swati-Sahu14/Selenium_assessment.git
```

### Open

Import the project into your Java IDE and configure the required Selenium dependencies.

### Execute

Open the required `Day_*` folder, select an assessment class and run it as a Java application.
